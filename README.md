# .github

Profile and default community files of the [Vallaury](https://github.com/Vallaury) organization.

- `profile/`: the page shown on the organization's profile (`README.md`, the banner, the download badges and the Ko-fi button).
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md`, `FUNDING.yml`, `PULL_REQUEST_TEMPLATE.md` and `ISSUE_TEMPLATE/`: the defaults of every repository that has no file of its own.
- `scripts/sync-labels.sh` and `scripts/labels.json`: the shared labels. Run `scripts/sync-labels.sh Vallaury/<repo>` for a new repository.
