# Aiuto / Getting help

- **Problemi con l'app o con il servizio** (accesso, orario, compiti, appunti): scrivi a [aiuto@vallaury.it](mailto:aiuto@vallaury.it) oppure usa le voci di aiuto dentro l'app.
- **Un errore nel codice di un'app o di un pacchetto:** apri una *issue* nel repository giusto e usa il modello.
- **Una domanda o un'idea:** usa le [Discussioni](https://github.com/orgs/Vallaury/discussions) dell'organizzazione.
- **Una vulnerabilità:** segui la [politica di sicurezza](SECURITY.md), non aprire una issue pubblica.
- **Dati personali e privacy:** [privacy@vallaury.it](mailto:privacy@vallaury.it).

*English: for help with the service write to aiuto@vallaury.it; for bugs in an app or package open an issue in the right repository; for questions and ideas use the organization's Discussions; for vulnerabilities follow the security policy; for privacy matters write to privacy@vallaury.it.*
